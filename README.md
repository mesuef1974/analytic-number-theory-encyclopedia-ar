## المرحلة التالية

الإصدار المخطط `0.16.0-dev` مخصص للفصل الثاني عشر:

**مبرهنة Siegel--Walfisz والتوزيع المنتظم للأعداد الأولية في المتتاليات الحسابية.**

تبدأ المرحلة بمنهج `EVIDENCE-FIRST / PRE-AUTHORING`، مع فصل صريح بين نتيجة الترديد الثابت في الفصل العاشر، وSiegel--Walfisz للترديدات \(q\le (\log x)^A\)، وBombieri--Vinogradov المؤجل إلى فصل لاحق.

## مبادئ التحرير

1. الدقة قبل الاختصار.
2. الفصل بين النتائج المثبتة، والنتائج المشروطة، والتخمينات.
3. إسناد كل ادعاء تاريخي أو بحثي إلى مصدر أصلي أو مرجع موثوق.
4. تقديم الحدس، ثم الصياغة الدقيقة، ثم البرهان، ثم التطبيقات.
5. تحديث فصل الجبهات الحديثة بحسب تاريخ إصدار كل نسخة.
6. عدم الادعاء بالشمول المطلق؛ فالموسوعة مشروع قابل للتحديث المستمر.
