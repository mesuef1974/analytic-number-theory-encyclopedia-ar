- المجال الممسوح: من 10 إلى 50 بخطوة 0.05.
- طريقة حساب زيتا: تحويل أويلر لسلسلة إيتا.
- طور ريمان–زيغل: `scipy.special.loggamma`.

- البيئة المرجعية: Python 3.12.13 وSciPy 1.17.0.
