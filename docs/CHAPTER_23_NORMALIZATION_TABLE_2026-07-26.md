# جدول تطبيعات الفصل الثالث والعشرين

## عد الأصفار

نكتب
\[
N(T)=\#\{\rho=\beta+i\gamma:0<\gamma\le T\},
\]
مع العد بالتعدد. الصيغة المرشحة للتجميد:
\[
N(T)=\frac{T}{2\pi}\log\frac{T}{2\pi}-\frac{T}{2\pi}+O(\log T).
\]

## متوسط التباعد والتطبيع المحلي

حول الارتفاع \(T\)، كثافة الأصفار المتوسطة هي تقريبًا
\[
\frac{1}{2\pi}\log\frac{T}{2\pi},
\]
ومن ثم يطبع فرق الأجزاء التخيلية بالصورة
\[
u=(\gamma-\gamma')\frac{\log T}{2\pi}.
\]

## نواة الجيب

نثبت لاحقًا اتفاقية واحدة:
\[
K(u)=\frac{\sin \pi u}{\pi u},
\qquad
R_2(u)=1-K(u)^2.
\]
عند \(u=0\) تؤخذ القيمة بالاستمرار.

## التحويل الفوري

قبل تجميد مبرهنة مونتغمري يجب اختيار إحدى الاتفاقيتين وتسجيلها حرفيًا:
\[
\widehat f(\alpha)=\int_{\mathbb R}f(u)e^{-2\pi i\alpha u}\,du
\]
أو الاتفاقية دون \(2\pi\). لا يسمح بالخلط بينهما عند ذكر مجال الدعم.

## دالة مونتغمري الموزونة

يحجز الرمز
\[
F(\alpha,T)
\]
للدالة الموزونة للأزواج بعد استخراج تعريفها الأصلي بدقة. لا يعتمد أي ثابت أو وزن قبل التحقق من النص الأصلي.
