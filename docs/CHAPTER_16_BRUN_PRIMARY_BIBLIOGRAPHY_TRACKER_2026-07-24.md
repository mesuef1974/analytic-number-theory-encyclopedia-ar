# متتبع الإحالة الأصلية لبرون — الفصل السادس عشر

آخر تحديث: 2026-07-24

```text
OBJECTIVE             = VERIFY PRIMARY BRUN BIBLIOGRAPHY
MATHEMATICAL-RESULT   = NOT BLOCKED
HISTORICAL-PRIORITY   = BLOCKED
REFERENCE-BLOCKERS    = 1
AUTHORING             = BLOCKED
```

## المطلوب إغلاقه

تثبيت سجل ببليوغرافي أولي موثوق لإحدى أوراق Viggo Brun المؤسسة التي تحمل نسبة النتيجة التاريخية المتعلقة بالأزواج الأولية أو تقارب مجموع مقلوباتها، مع:

- العنوان الأصلي كما نُشر؛
- سنة النشر؛
- اسم الدورية أو السلسلة؛
- المجلد والصفحات؛
- رابط فهرسي موثوق أو نسخة رقمية؛
- بيان واضح: هل الورقة نفسها تثبت تقارب مجموع مقلوبات الأوليات التوأم، أم أن النتيجة موزعة عبر عدة أوراق؟

## سياسة الفصل حتى الإغلاق

- لا تُنسب صياغة حديثة دقيقة إلى ورقة أصلية غير مفحوصة.
- يمكن إثبات تقارب مجموع برون داخل الفصل من حد عدّ علوي والجمع الجزئي.
- تبقى العبارة التاريخية عامة: «أثبت برون في أعماله المؤسسة للغربال تقارب مجموع مقلوبات الأوليات التوأم»، إلى أن يثبت الموضع الببليوغرافي الدقيق.
- لا تصدر بوابة `PASS-FOR-AUTHORING` قبل إغلاق هذا المتتبع أو اتخاذ قرار صريح بتحويل الإسناد التاريخي إلى مصدر ثانوي موثوق.
