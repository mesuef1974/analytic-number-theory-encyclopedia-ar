## الغرض والمنهج

هذا السجل يوثّق البحث الاستكشافي في Consensus الذي استُخدم أثناء مراجعة
أهداف المشروع والفصول 1--5. لا يُعامل Consensus بوصفه مصدرًا أوليًا أو
بديلًا عن البرهان؛ بل تُجلب البطاقة الكاملة لكل نتيجة، ثم تُطابق الدعوى مع
ورقة أصلية أو كتاب قياسي قبل إدخالها في المتن.

أُجريت عمليات البحث بمحاور: تعليم البرهان والأمثلة المحلولة، قابلية إعادة
الإنتاج والمراجعات الحية، دالة زيتا ومبرهنة الأعداد الأولية، الدوال
الضربية والتفاف ديريشليه وقلب موبيوس، سلاسل ديريشليه وصيغة بيرون. أعداد
الاستشهادات أدناه هي لقطة متغيرة بتاريخ التحديث.

## قرارات ناتجة عن الفحص

1. المصدر القياسي أو الأصلي يبقى المرجع النهائي للنتائج الرياضية.
2. تُسجّل النتائج المبرهنة والمقتبسة والمؤجلة بمعرّفات ثابتة.
3. لا تُنسب مبرهنة الأعداد الأولية إلى مجرد عدم انعدام (zeta) على
   (Re(s)=1)؛ يلزم ذكر بقية أدوات الانتقال التحليلي/التابيري.
4. تبقى صيغة بيرون ضمن النتائج المؤجلة حتى يثبت فصل مستقل فروضها وصيغ
   القطع والتنعيم.
5. تُراجع الأدلة الحية عند كل بوابة إصدار، مع تسجيل تاريخ البحث والقيود.
