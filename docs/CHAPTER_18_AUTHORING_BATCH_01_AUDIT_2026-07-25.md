# تدقيق دفعة التأليف الأولى للفصل الثامن عشر

التاريخ: 2026-07-25

## النطاق المنجز

- إنشاء متن الفصل الثامن عشر.
- إضافة نطاق الفصل وحالته ونواتج التعلم.
- تعريف المجاميع الأسية الموزونة وغير الموزونة.
- إثبات الحد التافه `ANT-ID-18-01`.
- إثبات الجمع الجزئي المنفصل `ANT-LEM-18-01`.
- إثبات متباينة فرق فان دير كوربوت `ANT-LEM-18-02` بالثابت الخارجي `(N+H-1)/H` والأوزان `(1-h/H)`.
- اشتقاق نسخة الأطوار ذات الفروق `f(n+h)-f(n)`.
- تنفيذ اختبار sanity على `z_n=1` ومنع ادخار وهمي.
- توضيح أن اختبار المشتقة الأولى سيعتمد `||f'(x)||` لا `|f'(x)|`.
- ربط الفصل بالمخطوط على فرع العمل فقط.

## فحص التصنيف

```text
ANT-ID-18-01   = AUTHORED-DRAFT / PROVED-HERE
ANT-LEM-18-01  = AUTHORED-DRAFT / PROVED-HERE
ANT-LEM-18-02  = AUTHORED-DRAFT / PROVED-HERE
OTHER RESULTS  = RESERVED / NOT YET AUTHORED
CITABILITY     = NON-CITABLE
```

## فحوص منطقية

1. الحد التافه ناتج مباشرة من متباينة المثلث.
2. الجمع الجزئي يفصل أداة نقل الأوزان عن مصدر الإلغاء.
3. برهان فرق فان دير كوربوت يمدد `z_n` بالصفر، ثم يطبق كوشي--شفارتس، ثم يعيد التجميع بحسب الفرق.
4. العامل `N+H-1` ينتج من عدد قيم الفهرس الخارجي بعد التمديد.
5. الوزن `H-h` ينتج من عدد أزواج الإزاحات ذات الفرق `h`.
6. عند `z_n=1` لا تنتج الصيغة ادخارًا غير حقيقي.

## البنود التالية

- كتابة اختبار المشتقة الأولى وبرهانه.
- إدراج اختبار المشتقة الثانية بحالة `CITED / EXPLAINED`.
- كتابة عملية `A` المحدودة.
- شرح عملية `B` وإطار الأزواج الأسية.
- بناء PDF كامل وفحص المراجع والإحالات.

```text
AUTHORING-BATCH-01 = COMPLETE-AS-DRAFT
PDF-BUILD          = PENDING
REFERENCE-AUDIT    = PENDING
MATHEMATICAL-AUDIT = BATCH-01 INITIAL PASS
PR-35              = DRAFT / OPEN / UNMERGED
MERGE              = NOT AUTHORIZED
RELEASE-READY      = NO
```
