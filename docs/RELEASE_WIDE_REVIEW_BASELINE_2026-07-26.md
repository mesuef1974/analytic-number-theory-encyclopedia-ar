```text
REVIEW-TYPE            = RELEASE-WIDE

CHAPTERS               = 1--26 IN MANUSCRIPT
LAST-CHAPTER           = 26
LOCAL-BUILD            = PASS / 321 PAGES
LOCAL-PDF-SHA256       = 1C18B040FF752E79870D319917CEF6FD8E01E9CABE7DAD6D35BFCEB0F54A000B
QUALITY-CHECK          = PASS
WORKTREE               = CLEAN
ISSUE                  = #53 / OPEN
RELEASE-READY          = NO
```

## هدف المراجعة

هذه المرحلة لا تضيف فصلًا جديدًا، ولا تعيد اعتماد الفصول منفردة. هدفها اختبار صلاحية الإصدار الكامل كوحدة واحدة من حيث الحوكمة والبناء وسجلات النتائج والاتساق التحريري والمراجع والروابط.

## محاور التدقيق

1. اتساق ملفات الحالة المركزية مع `0.30.0-dev` والفصول 1--26.
2. اتساق `docs/RESULTS_REGISTRY.md` مع سجلات الفصول واعتمادات المالك.
3. سلامة خريطة إدراج الفصول وترتيبها وعدم وجود ملفات مفقودة أو مكررة.
4. عدم وجود مراجع أو استشهادات معلقة في البناء النهائي.
5. تصنيف تحذيرات الخطوط و`Overfull \hbox` إلى حواجز أو ديون تحريرية.
6. فحص مفاتيح BibTeX والروابط الآلية المتاحة.
7. مراجعة التنبيهات القانونية والمنهجية وحدود الادعاء.
8. إعداد تقرير مستقل وحكم نهائي منفصل عن قرار المالك.

## اكتشافات خط الأساس

### RW-MAJOR-01 — وثائق مركزية متأخرة

`docs/ROADMAP.md` ما يزال يعرض المرحلة السادسة والفصول 22--26 بوصفها غير منجزة، رغم اكتمالها ودمجها.

### RW-MAJOR-02 — قائمة المهام متوقفة عند الفصل 21

`docs/TODO.md` ما يزال يضع تحديد الفصل 22 بوصفه الخطوة التالية، ولا يسجل إنجاز الفصول 22--26 ولا مرحلة مراجعة الإصدار.

### RW-CHECK-01 — تحذيرات الخطوط

البناء ناجح، لكن سجل XeLaTeX يتضمن رسائل `Missing character` لعربية دخلت سياق خط Latin Modern داخل قائمة المراجع. يلزم تحديد أثرها البصري قبل تصنيفها حاجزة أو غير حاجزة.

### RW-CHECK-02 — تجاوزات الصناديق

توجد تحذيرات `Overfull \hbox` في المتن والفهرس والمراجع. يلزم فرزها بحسب مقدار التجاوز والموضع والأثر البصري، لا عدها إجمالًا فقط.
