# جدول تطبيعات الفصل الثاني والعشرين

## الحالة

```text
NORMALIZATION = CORE FROZEN
AUTHORING     = BLOCKED PENDING INDEPENDENT REVIEW
```

| الرمز | المعنى | التطبيع المجمد |
|---|---|---|
| \(s\) | المتغير المركب | \(s=\sigma+it\) |
| \(I_k(T)\) | العزم المستمر من الرتبة \(2k\) على \([0,T]\) | \(\int_0^T|\zeta(1/2+it)|^{2k}\,dt\) |
| \(J_k(T)\) | العزم على النافذة الديادية | \(\int_T^{2T}|\zeta(1/2+it)|^{2k}\,dt\) |

| \(P_4(x)\) | كثيرة حدود العزم الرابع | درجة 4، ومعامل \(x^4\) هو \(1/(2\pi^2)\) |
| \(E_2(T)\) | خطأ العزم الرابع | \(I_2(T)-TP_4(\log T)\) |
| \(a(k)\) | العامل الحسابي | حاصل أويلر المجمد في سجل الأدلة |

| RH | فرضية ريمان | كل نتيجة مشروطة بها تحمل وسمًا صريحًا |

## الصيغ المرجعية

\[
I_1(T)=T\log\frac{T}{2\pi}+(2\gamma-1)T+E_1(T).
\]

\[
I_2(T)=\frac{1}{2\pi^2}T\log^4T+O(T\log^3T)
      =TP_4(\log T)+E_2(T).
\]

\[
I_k(T)\sim a(k)g_{KS}(k)T\left(\log\frac{T}{2\pi}\right)^{k^2}
\qquad\text{(Keating--Snaith; CONJECTURAL).}
\]

## قواعد إلزامية

- لا خلط بين \(k\) في \(I_k\) وبين رتبة العزم \(2k\).
- لا خلط بين \([0,T]\) و\([T,2T]\).
- عند تحويل نتيجة بين \(I_k\) و\(J_k\)، يجب تسجيل أن الفرق لا يغيّر الرتبة المقارنة فقط، ولا تُنقل الثوابت الحدسية بلا حساب.
- لا تُحذف عوامل \(T\) أو قوى \(\log T\).
- يُفصل معامل الحد الرئيس عن كثيرة الحدود الكاملة وعن حد الخطأ.
- يُكتب \(\log(T/2\pi)\) في حدسية Keating--Snaith كما في التطبيع المجمد؛ واستبداله بـ\(\log T\) مسموح فقط عند الحديث عن الرتبة.
- الصيغ الحدسية موسومة `CONJECTURAL` حتى لو وافقت الحالتين \(k=1,2\).
- لا يُستخدم الرمز \(g(k)\) وحده إذا كان قد يلتبس مع تطبيع \(g_k/\Gamma(k^2+1)\) في مراجع أخرى؛ المعتمد هنا \(g_{KS}(k)=G(k+1)^2/G(2k+1)\).
