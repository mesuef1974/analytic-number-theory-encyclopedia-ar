# جدول تطبيعات الفصل الثاني والعشرين

## الحالة

```text
NORMALIZATION = DRAFT / NOT FROZEN
AUTHORING     = BLOCKED
```

| الرمز | المعنى | التطبيع المعتمد مبدئيًا |
|---|---|---|
| \(s\) | المتغير المركب | \(s=\sigma+it\) |
| \(I_k(T)\) | العزم المستمر من الرتبة \(2k\) | \(\int_0^T|\zeta(1/2+it)|^{2k}\,dt\) |
| \(M_{2k}(T)\) | مرادف محتمل | لا يُستعمل مع \(I_k\) في السياق نفسه إلا بعد تصريح |
| \(a(k)\) | العامل الحسابي في حدسية العزوم | يُجمّد من المصدر الأصلي قبل الاستعمال |
| \(g(k)\) | العامل المصفوفي/الهندسي | يُجمّد من Keating--Snaith قبل الاستعمال |
| \(\max_{t\in[T,2T]}|\zeta(1/2+it)|\) | قيمة قصوى على نافذة | لا تُستنتج من العزوم دون حجة مستقلة |
| RH | فرضية ريمان | كل نتيجة مشروطة بها تحمل وسمًا صريحًا |

## قواعد إلزامية

- لا خلط بين \(k\) في \(I_k\) وبين رتبة العزم \(2k\).
- لا خلط بين متوسط \([0,T]\) ومتوسط نافذة \([T,2T]\).
- لا تُحذف عوامل \(T\) أو قوى \(\log T\) عند مقارنة النتائج.
- تُفصل الثوابت الرئيسية عن رتبة المقدار.
- تُصنف الصيغ الحدسية بعلامة `CONJECTURAL` حتى لو طابقت البيانات العددية أو نموذج المصفوفات العشوائية.
