# جدول تطبيعات الفصل الثاني والعشرين

## الحالة

```text
NORMALIZATION = PARTIALLY FROZEN
AUTHORING     = BLOCKED
```

| الرمز | المعنى | التطبيع المعتمد |
|---|---|---|
| \(s\) | المتغير المركب | \(s=\sigma+it\) |
| \(I_k(T)\) | العزم المستمر من الرتبة \(2k\) على \([0,T]\) | \(\displaystyle I_k(T)=\int_0^T|\zeta(1/2+it)|^{2k}\,dt\) |
| \(J_k(T)\) | عزم النافذة على \([T,2T]\) | \(\displaystyle J_k(T)=\int_T^{2T}|\zeta(1/2+it)|^{2k}\,dt\) |
| \(M_{2k}(T)\) | مرادف محتمل | لا يُستعمل في المتن لتجنب الخلط مع \(I_k,J_k\) |
| RH | فرضية ريمان | كل نتيجة مشروطة بها تحمل وسم `CONDITIONAL-ON-RH` |
| \(a(k)\) | العامل الحسابي في حدسية العزوم | غير مجمد حتى قراءة صيغة Keating--Snaith الأصلية |
| \(g(k)\) | العامل المصفوفي | غير مجمد حتى قراءة صيغة Keating--Snaith الأصلية |
| \(\mathcal M(T)\) | قيمة قصوى على نافذة | \(\displaystyle \max_{t\in[T,2T]}|\zeta(1/2+it)|\)؛ لا تُستنتج من العزوم دون حجة مستقلة |

## صيغ مقارنة مجمدة

### Soundararajan، تحت RH

\[
J_k(T)\ll_{k,\varepsilon}T(\log T)^{k^2+\varepsilon},
\qquad k>0,\ \varepsilon>0.
\]

### Harper، تحت RH

\[
J_k(T)\ll_k T(\log T)^{k^2},
\qquad k\ge0 \text{ ثابت}.
\]

الفارق الحاكم: Harper يزيل خسارة \(\varepsilon\) من أسّ اللوغاريتم، ولا يثبت ثابت Keating--Snaith.

## قواعد إلزامية

- لا خلط بين \(k\) في \(I_k,J_k\) وبين رتبة العزم \(2k\).
- لا خلط بين تكامل \([0,T]\) وتكامل \([T,2T]\)؛ الانتقال بينهما يُذكر صراحة.
- لا تُحذف عوامل \(T\) أو قوى \(\log T\) عند مقارنة النتائج.
- تُفصل الثوابت الرئيسية عن رتبة المقدار.
- يكتب مجال \(k\) وشرط RH بجانب كل مبرهنة، لا في فقرة بعيدة.
- `LOWER-BOUND-OF-CORRECT-ORDER` لا يعني `ASYMPTOTIC-FORMULA`.
- تُصنف صيغ Keating--Snaith بعلامة `CONJECTURAL`.
- لا تُحوّل حدود العزوم إلى نتائج قصوى إلا بأداة مستقلة مثل مبدأ الرنين أو تقديرات الانحرافات الكبيرة.
