# سجل معالجة نسخة النشر — v0.30.1

## الحالة العليا

```text
BASE-BRANCH          = main
WORK-BRANCH          = agent/publication-preview-remediation-v0.30.1
TARGET               = Publication Preview
FINAL-RELEASE        = BLOCKED
SCIENTIFIC-CORE      = STRONG / PARTIALLY-AUDITED
CURRENT-PHASE        = P0 TECHNICAL REMEDIATION
```

## رموز الحالة

| الرمز | المعنى |
|---|---|
| `OPEN` | لم يبدأ التحقق أو الإصلاح |
| `IN-PROGRESS` | جارٍ التحقق أو الإصلاح |
| `RESOLVED` | طُبّق الإصلاح في المصدر |
| `VERIFIED` | أُعيد البناء وتحقق الإصلاح بصريًا ونصيًا |
| `EXTRACTION-ONLY` | الخلل في استخراج النص لا في العرض المرئي |
| `REJECTED` | الملاحظة غير صحيحة بعد التحقق |
| `DEFERRED-P1` | صحيحة لكنها لا تمنع معاينة النشر |
| `DEFERRED-P2` | تطوير علمي مؤجل بعد إغلاق P0/P1 |

## قاعدة الإغلاق

لا تُغلق أي ملاحظة عند `RESOLVED` فقط. الإغلاق النهائي يتطلب:

1. تحديد السبب الجذري.
2. تعديل المصدر أو أداة البناء.
3. نجاح فحوص الجودة والبناء.
4. فحص PDF بصريًا.
5. فحص النص المستخرج عند ارتباط الملاحظة بطبقة النص.
6. تسجيل الالتزام والدليل والنتيجة هنا.

# P0 — عيوب تمنع النشر

## PUB-P0-001 — تسرب ماكرو الاتجاه إلى الفهارس الثلاثة

- **الحالة:** `IN-PROGRESS`
- **الادعاء التحكيمي:** ظهور `ensure@LTR` بعد أرقام صفحات الفهارس، مع عدد كبير من التكرارات في الصفحات الأخيرة.
- **النطاق:** فهرس العلماء، فهرس النظريات والنتائج، فهرس الرموز والمصطلحات.
- **المطلوب للتحقق:**
  - فحص تعريفات `ensure@LTR` و`hyperpage` وماكرو أرقام الفهرس.
  - فحص ملفات `.idx` و`.ind` الناتجة.
  - فحص العرض المرئي والنص المستخرج للصفحات الأخيرة.
- **معيار الإغلاق:** صفر ظهور مرئي أو مستخرج لـ`ensure@LTR`، مع بقاء الروابط واتجاه أرقام الصفحات صحيحين.
- **آخر تحديث:** بدأ التحقيق في السبب الجذري.

## PUB-P0-002 — لغة الحوكمة وعملية التأليف داخل متن القارئ

- **الحالة:** `OPEN`
- **أمثلة مبلغ عنها:** «حالة المستودع الحالية»، «دفعة التأليف»، «قرار المالك الصريح»، «اعتماد المالك»، «بعد نجاح البناء».
- **معيار الإغلاق:** صفر ظهور لعبارات الحوكمة في نسخة النشر مع بقائها في نسخة التدقيق ووثائق المشروع.

## PUB-P0-003 — إحالات فارغة أو أهداف مرجعية محذوفة

- **الحالة:** `OPEN`
- **المواضع المبلغ عنها:** ص129 ×3، ص136، ص137، ص155.
- **معيار الإغلاق:** صفر `??` وصفر إحالة مرئية بلا رقم أو عنوان، مع نجاح جميع الإحالات الداخلية.

## PUB-P0-004 — قسم فارغ §13.13 «حدود الادعاء»

- **الحالة:** `OPEN`
- **المطلوب:** التحقق من كونه فارغًا فعلاً؛ ثم كتابة محتوى علمي مناسب أو حذف العنوان.
- **معيار الإغلاق:** لا عنوان قسم بلا متن فعلي.

## PUB-P0-005 — مراجعة بدايات جميع الفصول لبيانات الإعداد

- **الحالة:** `OPEN`
- **المطلوب:** فحص بداية كل فصل في PDF المنشور ومصدر النشر المولد.
- **معيار الإغلاق:** تبدأ الفصول بمتن موجّه للقارئ لا بحالة تحريرية أو معلومات بناء.

## PUB-P0-006 — تدقيق بصري للترقيم واتجاه الإحالات والمعادلات

- **الحالة:** `OPEN`
- **أمثلة مبلغ عنها:** ترقيم من نمط `0.1.2`، اضطراب معادلة `π(x)`، مراجع مختلطة RTL/LTR.
- **قاعدة الحكم:** الفصل بين `VISUAL-RENDER` و`TEXT-EXTRACTION` قبل أي تعديل.
