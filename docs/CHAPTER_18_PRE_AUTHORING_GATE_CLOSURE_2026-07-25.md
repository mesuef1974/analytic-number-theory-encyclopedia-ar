# إغلاق بوابة ما قبل التأليف للفصل الثامن عشر

التاريخ: 2026-07-25

## القرار

بعد اكتمال سجل الأدلة، وخريطة البرهان، ومسح Consensus، وتجميد التطبيع والتصنيفات، وتدقيق عدم الدور، والمراجعة المستقلة لمتباينة فرق فان دير كوربوت واختبار المشتقة الأولى، تقرر:

```text
PRE-AUTHORING-GATE  = CLOSED
PASS-FOR-AUTHORING  = YES
AUTHORING           = AUTHORIZED ON WORK BRANCH
RESULTS             = 8 / AUTHORIZED-FOR-DRAFTING / NON-CITABLE
PR-35               = DRAFT / OPEN / UNMERGED
MERGE               = NOT AUTHORIZED
RELEASE-READY       = NO
```

## أساس القرار

1. صيغة متباينة فرق فان دير كوربوت صحيحة بالعامل الخارجي والأوزان الطرفية المجمدة.
2. اختبار المشتقة الأولى مجمد بالمسافة إلى الأعداد الصحيحة مع الرتابة المناسبة.
3. الحالات الثابتة والخطية متوافقة مع الصياغة، والحالة التربيعية لا تكشف تعارضًا.
4. اختبار المشتقة الثانية وعملية `B` وإطار الأزواج الأسية بقيت مقتبسة ضمن حدود الادعاء.
5. تدقيق عدم الدور مع الفصل 17 ناجح.

هذا الإغلاق يسمح بإنشاء متن الفصل وربطه بالمخطوط على فرع العمل فقط، ولا يسمح بالدمج أو الترقية إلى `REVIEWED`.
