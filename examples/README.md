# الأمثلة الحاسوبية

يحتوي هذا المجلد على تجارب قابلة لإعادة الإنتاج مرتبطة بفصول الموسوعة.

## البنية

- `python/`: أمثلة Python.
- `sage/`: أمثلة SageMath.
- `pari-gp/`: أمثلة PARI/GP.
- `mathematica/`: دفاتر أو شيفرات Wolfram Language.

## القواعد

1. يجب أن يذكر كل مثال الفصل والقسم المرتبطين به.
2. يجب تسجيل إصدار الأداة والمكتبات.
3. يجب فصل النتائج التجريبية عن البراهين.
4. يجب تثبيت البذرة العشوائية عند استخدام العشوائية.
5. يجب أن تكون المخرجات قابلة لإعادة الإنتاج.
